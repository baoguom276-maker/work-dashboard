# Deploy to Cloudflare Pages

This project is a static website. Deploy it with these Cloudflare Pages settings:

- Framework preset: None
- Build command: leave empty
- Build output directory: `/`
- Root directory: `/`

Notes:

- The app stores data in each visitor's browser `localStorage`.
- Deploying this version is good for demo and personal use.
- Shared team data requires a future cloud database and login layer.
